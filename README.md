# EM Project
This project aims to analyze data from the American WAKE experimeNt (AWAKEN). This data was taken from a Cessna F406 and was used to study wake produced by wind farms. It takes this data and uses the GeoScatter function from MATLAB to plot wind speed taken along the aircraft's flight path. To better view the effects of wake, a portion of this data not related to the wind farms is cut out, and only the upwind and downwind parts of the data are plotted for simplicity.

All relevant plots can be found in Output.
